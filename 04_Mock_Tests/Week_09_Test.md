**Q1 — (B).** AM produces upper and lower sidebands, each of width fₘ → total **2fₘ**.

**Q2 — (A).** DSB-SC suppresses only the carrier, keeping both sidebands → **2fₘ**. SSB transmits one sideband → **fₘ**, halving the bandwidth at the cost of a more complex receiver.

**Q3 — (B).** P_total = P_c(1 + μ²/2) — carrier power plus μ²/2 times the carrier in the sidebands.

**Q4 — (B).** At μ = 1: P_total = 1.5 P_c, sideband power = 0.5 P_c. Fraction = 0.5/1.5 = **33.3%**. Two-thirds of AM's transmitted power is in the carrier, which carries no information — the reason DSB-SC and SSB exist.

**Q5 — (C).** Carson's rule: BW ≈ **2(Δf + fₘ)**. For narrowband FM (Δf ≪ fₘ) it reduces to 2fₘ, matching AM.

**Q6 — (A).** "White" means a **flat PSD** across all frequencies (by analogy with white light). Its autocorrelation is an impulse at zero lag — non-zero at τ = 0, so option C is wrong. Whiteness concerns the spectrum; Gaussianity is a separate, independent property.

**Q7 — (B).** Nyquist rate = **2fₘ**. Sampling below it causes aliasing.

**Q8 — (B).** C = B log₂(1 + S/N) = 3000 × log₂(1 + 3) = 3000 × log₂4 = 3000 × 2 = **6000 bps**.

**Q9 — (B).** Entropy is maximised by a uniform distribution, giving H = **log₂M** bits/symbol. For M = 2 that is 1 bit.

**Q10 — (A).** The r parity bits must index all m + r bit positions plus the no-error case → **2ʳ ≥ m + r + 1**. For m = 4: r = 3 works (8 ≥ 8).

**Q11 — (B).** The matched filter correlates the received signal with the known transmitted pulse shape, maximising output SNR in additive white Gaussian noise.

**Q12 — (C).** CDMA gives every user the whole band all the time, separating them by orthogonal/pseudo-random spreading codes. TDMA separates by time slot (A), FDMA by frequency band (B).

**Q13 — (A).** Mean = (2+3+3+5+7)/5 = 20/5 = **4**. Median (middle of the sorted list) = **3**. Mode (most frequent) = **3**.

**Q14 — (B).** Binomial: mean = np, variance = np(1 − p) = npq. Note the variance is always *less* than the mean here.

**Q15 — (C).** The Poisson distribution's defining quirk: **mean = variance = λ**.

**Q16 — (B).** Exponential with rate λ has mean **1/λ** and variance 1/λ². It is the memoryless continuous distribution — the waiting time between Poisson events.

**Q17 — (B).** P = (3/5) × (2/4) = 6/20 = **3/10**. Option A (9/25) is the answer *with* replacement — check which the question asks.

**Q18 — (B).** Bayes: P(A|D) = P(D|A)P(A) / [P(D|A)P(A) + P(D|B)P(B)] = (0.02 × 0.6) / (0.02 × 0.6 + 0.05 × 0.4) = 0.012 / 0.032 = **0.375**.

**Q19 — (B).** The empirical rule: ~**68%** within 1σ, ~95% within 2σ, ~99.7% within 3σ.

**Q20 — (A).** Independence means the joint probability factorises: **P(A ∩ B) = P(A)P(B)**, equivalently P(A|B) = P(A). Option B defines *mutually exclusive* events — independent and mutually exclusive are not the same thing (in fact, for events of non-zero probability, they are incompatible).

**Q21 — (B).** *Prudent* = acting with care and thought for the future; **wise and cautious**.

**Q22 — (B).** The standard collocation is *divided **in** its opinion* (also "divided in opinion"). *Divided on* takes an issue, not an opinion.

**Q23 — (B).** The pattern is a × b − b: 5×4 − 4 = 16? No — check the intended rule: 5×4 = 20, minus 5 = 15 ✓; 7×6 = 42, minus 7 = 35 ✓; 9×8 = 72, minus 9 = 63 ✓. So 11×10 = 110, minus 11 = **99**.

**Q24 — (B).** Let ages be 3x and 5x. (3x + 10)/(5x + 10) = 5/7 → 7(3x + 10) = 5(5x + 10) → 21x + 70 = 25x + 50 → 4x = 20 → x = 5. A's age = 3 × 5 = **15 years**.

**Q25 — (B).** Tripura is surrounded on three sides by **Bangladesh**, sharing about 856 km of international border — the third-longest of any Indian state with Bangladesh. Domestically it borders only Assam and Mizoram.
