# Week-wise Question Banks & Mock Tests

One comprehensive **question bank** per week, aligned to `01_Study_Plan/12_Week_Study_Plan.md`. Each bank now holds **150–215 questions** covering *every* subtopic of that week's syllabus section, drawn from the patterns of real previous-year competitive papers (GATE CSE, ISRO, NIELIT, UGC-NET, and the Kerala/Arunachal state-PSC computer-science papers).

**Total across the 12 weeks: ~2,150 practice questions**, each with a worked answer and detailed reasoning.

---

## What each file contains

Every `Week_XX_Test.md` has three sections, in order:

1. **The questions** — grouped into lettered/numbered *Parts* by subtopic, so you can see all topics are covered and can drill one area at a time. Each question has four options (A)–(D) with exactly one correct answer.
2. **✅ Answer Key** — a compact table mapping every question to its letter.
3. **📝 Detailed Solutions** — for *every* question: the correct letter plus 2–4 sentences of reasoning, with the full calculation shown for numericals.

⚠ **Do not scroll to the answer key until you have attempted a batch.**

---

## How to use a bank

These are **banks, not single sittings.** Do not try to do 180 questions in one go.

| | |
|---|---|
| **Batch size** | Attempt **25–30 questions at a time**, timed at ~30 minutes (the real ~63 sec/question pace) |
| **Marking** | **+1 correct, −1/3 wrong, 0 unattempted** (assume TPSC's negative marking) |
| **Conditions** | Closed book. Phone away. No calculator. Write answers on paper first. |
| **Cadence** | Do the first batch on the Sunday of that week; use the remaining batches through the following weeks as spaced revision and in the Week-12 run-up. |

⭐ **Because each Part is a distinct subtopic, you can also use the banks diagnostically:** if a mock or the weekly test exposes a weak area, drill just that Part.

## How to review (this matters more than the attempt)

Spend **at least twice as long reviewing as attempting.**

1. Mark the batch honestly, applying the −1/3 penalty.
2. For every wrong answer, classify the cause: `concept-gap` · `formula-forgotten` · `misread-question` · `calculation-slip` · `time-pressure`.
3. Copy each wrong answer into the error log in `01_Study_Plan/Weekly_Progress_Tracker.md` with the correct reasoning in **one line**.
4. **Also review the ones you got right by guessing** — a lucky guess is a gap you have not found yet.
5. Read the 📝 detailed solution for every question you missed; the reasoning, not the letter, is the point.

## Score interpretation (per 25-question batch)

| Score /25 | Reading |
|---|---|
| 20+ | Subtopic is solid. Move to the next Part. |
| 15–19 | Acceptable. Re-drill the 2–3 areas you missed. |
| 11–14 | Weak. Add 2 hours of this subject to next week and redo the Part. |
| ≤10 | Re-study the subtopic from `05_Notes/` before continuing. |

**The Paper-I questions in each bank are a health check, not full practice.** Real Paper-I practice is the daily 1-hour slot ([Paper1 notes](../05_Notes/Paper1_English_Reasoning_GK.md)). If you consistently score below 60% on them here, treat it as the early warning the study plan describes in §10.

## Sources & reliability

Questions are grounded in the authoritative subject notes in [`05_Notes/`](../05_Notes/) and modelled on real previous-year competitive papers. Answer keys and numerical solutions were cross-checked, but with ~2,150 questions a stray error is always possible — **if a keyed answer ever disagrees with the reasoning in its solution or with the notes, trust the notes and flag it.**
