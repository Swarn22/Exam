# Week-wise Mock Tests

One topic test per week, aligned to `01_Study_Plan/12_Week_Study_Plan.md`. Take each on the **Sunday morning** of its week.

---

## Format of every weekly test

| | |
|---|---|
| Questions | **25** — 20 from the week's Paper-II subject + 5 from Paper-I |
| Time | **30 minutes** (matches the real ~63 seconds/question pace) |
| Marking | **+1 correct, −1/3 wrong, 0 unattempted** (assume TPSC's negative marking) |
| Conditions | Closed book. Phone away. No calculator. Write answers on paper first. |

The answer key and explanations are at the bottom of each file. **Do not scroll down until the timer stops.**

## How to review a test (this matters more than the attempt)

Spend **at least twice as long reviewing as attempting.**

1. Mark it honestly, applying the −1/3 penalty.
2. For every wrong answer, classify the cause: `concept-gap` · `formula-forgotten` · `misread-question` · `calculation-slip` · `time-pressure`.
3. Copy each wrong answer into the error log in `01_Study_Plan/Weekly_Progress_Tracker.md` with the correct reasoning in **one line**.
4. **Also review the ones you got right by guessing.** A lucky guess is a gap you have not found yet.
5. Record the score in the tracker scoreboard.

## Score interpretation

| Score /25 | Reading |
|---|---|
| 20+ | Subject is solid. Move on; revisit only in Week 12. |
| 15–19 | Acceptable. Re-drill the 2–3 sub-topics you missed. |
| 11–14 | Weak. Add 2 hours of this subject to next week. |
| ≤10 | Re-study the subject. Do not carry the gap forward — these are all high-weightage sections. |

**The 5 Paper-I questions in each test are a health check, not real practice.** Real Paper-I practice is the daily 1-hour slot. But if you are consistently scoring below 3/5 here, treat it as the early warning the study plan describes in §10.
