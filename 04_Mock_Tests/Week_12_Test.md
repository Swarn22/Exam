**Q1 — (A).** Favourable pairs summing to 9: (3,6), (4,5), (5,4), (6,3) = 4 out of 36 = 4/36 = **1/9**. *(Option D is the same value unsimplified — if a paper offers both forms, pick the simplified one, but note the trap.)*

**Q2 — (C).** With n variables there are 2ⁿ rows in the truth table, and each row's output can be 0 or 1 → 2^(2ⁿ) functions. For n = 3: 2⁸ = **256**.

**Q3 — (A).** Group into nibbles from the right: `1011` `0110` = B, 6 → **B6**.

**Q4 — (B).** Sets = total lines / associativity = 128 / 2 = **64**. The block size is irrelevant to this particular count — a deliberate distractor.

**Q5 — (C).** n = log₂L = log₂256 = **8** bits per sample.

**Q6 — (B).** Every pair of distinct vertices can have at most one edge: C(n,2) = **n(n−1)/2**. For a *directed* graph it would be n(n−1).

**Q7 — (C).** Pointer arithmetic scales by the pointee size: p + 3 advances by 3 × 4 = **12 bytes**.

**Q8 — (B).** On sorted input, insertion sort's inner loop exits immediately, so each of the n−1 elements costs O(1) → **O(n)**. This adaptivity is why it is used for small or nearly-sorted arrays.

**Q9 — (B).** **Kruskal's** sorts edges globally and adds the cheapest that does not create a cycle (tested with union–find). Prim's instead grows a single tree from a start vertex.

**Q10 — (C).** Undeclared identifiers, type mismatches and scope violations are **semantic** errors. The lexer would happily tokenise the name; the parser would accept the syntax.

**Q11 — (C).** **FCFS** runs each process to completion. Round Robin, SRTF and preemptive priority all interrupt the running process.

**Q12 — (B).** Running → **waiting/blocked** on an I/O request. Running → ready happens on preemption. Confusing these two is the classic process-state error.

**Q13 — (C).** `DROP TABLE` removes the structure and the data. `DELETE` removes rows (and can be rolled back, with a `WHERE` clause); `TRUNCATE` removes all rows but keeps the structure.

**Q14 — (B).** The Cartesian product pairs every tuple of R with every tuple of S: 5 × 3 = **15** tuples. Its *degree* is the sum of the two degrees.

**Q15 — (B).** The Software Requirements Specification is the output of the **requirement analysis and specification** phase, and becomes the contract for design and testing.

**Q16 — (C).** /20 leaves 32 − 20 = 12 host bits → 2¹² = **4096** addresses (4094 usable).

**Q17 — (B).** A **switch** forwards frames using a MAC address table — layer 2. Hubs and repeaters are layer 1 (they simply regenerate signals); routers are layer 3.

**Q18 — (C).** 404 = Not Found. Classes: 2xx success, 3xx redirection, 4xx client error, 5xx server error.

**Q19 — (B).** A **Distributed** Denial of Service attack uses a botnet of compromised hosts to exhaust the target's bandwidth or resources.

**Q20 — (C).** Under IaaS the provider secures the physical infrastructure, hypervisor and network; the **customer** is responsible for the guest OS, runtime, applications and data — including patching. The split moves further toward the provider in PaaS and SaaS.

**Q21 — (B).** *Frugal* = economical, sparing with resources; its opposite is **extravagant**. A, C and D are all synonyms.

**Q22 — (B).** The correlative pair is *Hardly … **when***, not *than*. (*Scarcely … when*; *No sooner … than*.) It should read "Hardly had he reached the station **when** the train started moving."

**Q23 — (C).** At 3:00 the minute hand is at 12 and the hour hand at 3, i.e. 3 hour-marks apart. Each hour-mark is 30°, so the angle is 3 × 30 = **90°**.

**Q24 — (B).** Girls = 40% of 60 = 24. After 6 join: 30 girls out of 66 students = 30/66 = 5/11 ≈ **45.45%**. Note the *total* also increases — forgetting that gives 30/60 = 50%, option C, the intended trap.

**Q25 — (A).** **Merger with the Indian Union (15 October 1949) → Union Territory (1956, under the States Reorganisation Act) → full statehood (21 January 1972).**
