# State PSC & Equivalent Recruitment — Previous Year Questions

Previous-year questions from **recruitment exams for the same kind of post** as TPSC Assistant Technical Officer (IT): state-PSC IT/programmer/system-analyst posts, and national CS/IT officer recruitment at the same difficulty level.

Everything here is **organised into the same subject folders as the TPSC syllabus**, so a week of the study plan maps to exactly one folder.

---

## Why these exams and not others

TPSC has **not** conducted this ATO (IT) post before under the Tripura Information Technology Service Rules, 2025 — the 2026 advertisement is the first recruitment under these rules, so there is no direct TPSC precedent paper. TPSC's own [Old Question Paper archive](https://tpsc.tripura.gov.in/old-question-paper) currently holds only departmental exams (IAS/TCS, IPS/TPS, Engineering Officers, Auditors) with no CS/IT technical paper.

So the corpus below is built from exams that match on **syllabus and post profile**:

| Source | Post | Why it matches |
|---|---|---|
| **Kerala PSC** | Deputy Manager (IT) / Assistant Programmer, System Analyst / Computer Programmer, Lecturer in Computer Science / Computer Application, Computer Assistant | The closest state-PSC analogue: gazetted IT officer posts, MCQ format, CS+IT syllabus with GK |
| **Arunachal Pradesh PSC** | Assistant System Manager, Computer Programmer, Assistant Programmer, AE/JE (Computer Engineering) | **A Northeast state commission** with the same paper structure as TPSC ATO: a General English paper, a General Knowledge paper *and* a separate technical CS paper |
| **ISRO** | Scientist/Engineer 'SC' — Computer Science | Same subject list, same MCQ difficulty band, includes the non-GATE sections (SE, web, cloud) |
| **NIELIT** | Scientist-B / Technical Assistant (CS & IT) | Government IT-department recruitment; heavy on aptitude + applied IT, exactly like Paper-I + Paper-II here |
| **UGC-NET** | Computer Science & Applications | The single richest source for Software Engineering, Web Technologies, AI and general IT theory |

### Why only two state commissions?

I checked the obvious candidates. Most state PSCs simply do not publish CS/IT post papers:

| Commission | Result |
|---|---|
| **Kerala PSC** | ✅ Publishes official papers + answer keys per exam code |
| **Arunachal Pradesh PSC** | ✅ Publishes papers per post under "Previous Year Questions" |
| **TPSC (Tripura)** | ❌ [Archive](https://tpsc.tripura.gov.in/old-question-paper) holds only departmental exams (IAS/TCS, IPS/TPS, Engineering Officers, Auditors) — no CS/IT technical paper. This ATO post is also being recruited for the first time under the ITS Rules, 2025, so no precedent paper exists. |
| **TNPSC** | ❌ [Previous questions page](https://tnpsc.gov.in/english/previous-questions.html) lists civil/mechanical/electrical/textile/chemical engineering only — no computer science post |
| **WBPSC, APPSC (Andhra), UPPSC, MPPSC, OPSC, RPSC** | ❌ No stable public PDFs for IT posts — papers sit behind session-based portals, or only third-party reproductions exist |

Rather than fill the gap with unverifiable third-party scans, the corpus is completed with **ISRO, NIELIT and UGC-NET**, which match this syllabus closely and come with worked solutions.

## How to use this folder

1. **Week N of the study plan → open the matching `Paper2_SNN_*` folder.** Do the state-PSC questions *after* the GATE questions for the same subject (Friday in the weekly rhythm). They are easier and broader — good for confidence and coverage, weaker for depth.
2. **Sections 4, 10, 12, 13, 14 exist only here.** GATE has zero coverage. ~31 marks of Paper-II. Prioritise `Paper2_S10_*` (337 questions) — Software Engineering is the biggest untapped block in the whole paper.
3. **Use the Kerala PSC papers as full mocks**, not as practice sets. Time them at 1 hour 15 min for 100 questions, then mark against the official key.
4. **Note the format difference:** state-PSC questions are more *definitional* ("Which of the following is NOT a property of…"), GATE questions are more *analytical*. The TPSC paper, at 120 questions in a shared 180-minute slot, will sit closer to the state-PSC style — roughly 65 seconds per question leaves little room for long derivations.

## Gaps you must fill from outside this corpus

No question bank covers these; they need direct study:

- **OWASP Top 10** — learn all ten by name ([owasp.org/Top10](https://owasp.org/www-project-top-ten/))
- **IoT and blockchain** — barely represented; use a UGC-NET Paper-II guide or NPTEL notes
- **Cloud technology** — only 8 questions here for a ~4-mark section; study IaaS/PaaS/SaaS, deployment models, virtualisation, containers and edge computing directly
- **HTML5/CSS3/MVC/web services specifics** — the 65 web questions skew old; supplement with current material
- **Paper-I General Knowledge & Current Affairs (20 marks)** — nothing in any CS bank. Tripura GK, Northeast, Indian history/geography and current affairs must be built separately. See §6 of the study plan.
